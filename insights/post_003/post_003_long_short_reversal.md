## Core Insight

6yr aggregate still shows Long advantage (+0.73pp EV) — but the **trend is strongly negative**.
The gap went from +1.84pp (2020-21) to −0.24pp (2025-26).

If trajectory continues, shorts will systematically outperform longs in 2026+.
Long-biased parameter tuning (e.g., tighter long SL, wider long TP) built on 2020-22 data is likely overfitting.
